## 📋 Step-by-Step Platform Updates

### Instagram (@dadstillhere)
1. Go to Settings → Edit Profile
2. Change Profile Picture → Upload circular logo
3. Update Bio:
   ```
   Still loving them. Still here. ❤️
   📝 Letters • 🎥 Stories • 🔒 Private Journal
   A safe space for parents navigating estrangement.
   ```
4. Change Link to: https://dadstillhere.com
5. Create Story Highlights (5):
   - Letters
   - Stories
   - Resources
   - Community
   - Self-Care

### Facebook (dad-still-here)
1. Go to Page → Edit Profile
2. Click on cover photo → Upload landscape design
3. Update Profile Picture → Upload circular logo
4. Edit Page → About section:
   ```
   A safe, dignified space for parents living through distance, silence, and estrangement.
   
   Still loving them. Still here. ❤️
   ```
5. Add to Bio:
   - Website: dadstillhere.com
   - Category: Community
   - Contact: support@dadstillhere.com

### YouTube (Dad Still Here)
1. Click on Profile Picture → Customize Channel
2. Upload Banner: Door visual (2560x1440px)
3. Upload Profile Picture: Circular logo
4. Edit About section with complete description (see guide)
5. Create Playlists: Stories, Letters, Resources, Community, Weekly

### Twitter/X (@dadstillhere)
1. Click Settings & Privacy → Account
2. Edit Profile → Upload circular logo
3. Add Banner: Door visual (1500x500px)
4. Update Bio:
   ```
   Still loving them. Still here. 💙
   Letters • Stories • Community for parents navigating estrangement
   dadstillhere.com
   ```
5. Pin tweet: Introduction to the community

### Google Business Profile
1. Go to https://share.google/zplmWJDMgqjb3wE2r
2. Click Manage Profile
3. Upload Profile Picture: Circular badge logo (1000x1000px)
4. Add Business Description:
   ```
   Dad, Still Here is a safe, dignified media and community platform for parents experiencing child estrangement, parental alienation, and family separation. We provide a space to share stories, write letters, maintain private journals, and connect with others navigating similar experiences.
   ```
5. Website: https://dadstillhere.com
6. Add Photos: Upload door visual and featured content
7. Create Posts: Weekly updates, featured letters, community highlights
8. Add Opening Hours: Always Open
9. Business Category: Community
